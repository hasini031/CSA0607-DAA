CSA06 CO1 Assessment – ShopSphere Scalability Audit

1. Project Overview

This project analyzes the efficiency and scalability of algorithms used in the ShopSphere e-commerce platform.

2. Objectives

- Analyze algorithm time and space complexity.
- Calculate the number of basic operations.
- Apply the Master Theorem and substitution method.
- Compare linear search and binary search.
- Evaluate scalability for one million products.

3. Technologies Used

- Programming Language: Python
- Execution Environment: Google Colab
- Version Control: GitHub

4. Project Structure

- `Question_1/Source_Code/` – Python source code.
- `Question_1/Report/` – Assessment report and execution screenshots.

5. Modules Analyzed

- M1: Duplicate-Listing Detector
- M2: API Rate Limiter
- M3: Product Search
- M4: Recommendation Engine
- M5: Sales Analytics Engine

6. How to Run

1. Open Google Colab.
2. Create a new notebook.
3. Copy the Python code into a code cell.
4. Click Run to execute the program.
5. Check the operation counts and complexity results.

7. Expected Outcome

The project identifies inefficient algorithms and recommends improvements to help ShopSphere process a growing product catalogue efficiently.
