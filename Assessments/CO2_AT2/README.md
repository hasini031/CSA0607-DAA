# CO2 – Assessment Tool 2: Debugging and Optimization

## Project Title
**SOC Alert-Triage Module of SentinelOps**

## Course Details
- **Course Code:** CSA0607 – Design and Analysis of Algorithms
- **Assessment:** CO2 – Debugging and Optimization Task
- **Topic:** Brute Force Techniques for Sorting, Searching, String Matching, and Closest-Pair Problems

## Project Description
This project focuses on identifying defects, debugging Python functions, and optimizing algorithms used in the SentinelOps Security Operations Centre (SOC) Alert-Triage Module.

The module handles alert sorting, blocked IP address searching, attack signature matching in logs, and finding the closest pair of login locations.

## Objectives
1. Identify and explain defects in the original Python program.
2. Correct the faulty functions and verify their outputs.
3. Optimize the corrected algorithms without changing their intended results.
4. Analyze time complexity and basic operation counts.
5. Compare algorithm performance using experimental results.
6. Develop a test harness covering normal and boundary cases.

## Repository Structure
- `Pseudocode/` – Original, corrected, and optimized pseudocode.
- `Source_Code/` – Python implementations, test harness, and benchmark program.
- `Report/` – Debugging report, complexity analysis, tables, and graphs.
- `Supporting_Files/` – Test datasets, execution logs, and benchmark results.

## Algorithms Covered
- Insertion Sort
- Sequential Search
- Brute-Force String Matching
- Closest-Pair Computation

## Testing and Analysis
The final implementation will be tested using the assessment's sample data and boundary cases. Performance experiments will compare sorting operations and closest-pair distance computations for different input sizes.

## Conclusion
This project demonstrates systematic debugging, algorithm optimization, correctness verification, and time-complexity analysis for the SentinelOps SOC Alert-Triage Module.
