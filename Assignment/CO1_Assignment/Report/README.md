# CO1 Assignment – Report

## 1. Overview
This folder contains the report documentation and supporting evidence for the CO1 assignment on the design and analysis of searching algorithms for a large-scale student database.

## 2. Folder Contents

### Source_Code_Screenshots
Contains screenshots of the Python source code used to implement Linear Search, Recursive Binary Search, and Hash Table Search.

### Output_Screenshots
Contains screenshots of the actual program execution output obtained from Google Colab, including correctness checks and performance measurements.

### Analysis
Contains mathematical derivations, time and space complexity analysis, best-, average-, and worst-case analysis, asymptotic analysis, recurrence formulation, recurrence solution, and interpretation of experimental results.

### Tables_and_Graphs
Contains complexity comparison tables, experimental performance tables, and graphs comparing algorithm performance for different dataset sizes.

### Documentation
Contains the complete CO1 assignment report in Word format, covering all 12 tasks and the prescribed report requirements.

## 3. Tools Used
- Python
- Google Colab
- GitHub
- Microsoft Word

## 4. Submission Evidence
All screenshots and experimental results must be generated from the actual program execution. Performance tables and graphs must use measured results rather than invented values.

## 5. Conclusion
This folder organizes the documentation, analysis, experimental evidence, tables, and graphs required for the CO1 assignment.
