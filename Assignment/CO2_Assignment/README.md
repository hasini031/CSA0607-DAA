# CO2 Assignment 2 – Design and Analysis of Algorithms

## 📌 Project Overview

This repository contains the solutions for **CO2 Assignment 2** of the course **CSA06 – Design and Analysis of Algorithms**. It includes algorithm design, pseudocode, Python implementations, test cases, output screenshots, complexity analysis, and performance comparisons.

The assignment focuses on implementing and analyzing different algorithms and understanding their efficiency under various input conditions.

## 🎯 Objectives

- Design algorithms to solve the given problems.
- Develop pseudocode and Python implementations.
- Test algorithms using different input datasets.
- Analyze time and space complexity.
- Compare algorithm performance using experimental results.
- Understand the advantages and limitations of brute-force and exhaustive-search approaches.


## 📝 Assignment Questions

### Q1 – Sorting Algorithms
Implement and compare Selection Sort, Bubble Sort, and Insertion Sort using different input conditions, such as sorted, reverse-sorted, and nearly sorted data.

### Q2 – Sequential Search
Implement sequential search to locate an item in a maintenance tool register and analyze the number of comparisons required.

### Q3 – Brute-Force String Matching
Implement brute-force string matching to find a pattern within a given text and evaluate the number of character comparisons.

### Q4 – Brute-Force Closest Pair
Find the closest pair of points by calculating distances between all possible pairs of points and analyze the algorithm's performance.

### Q5 – Brute-Force Convex Hull
Identify the convex hull of a set of points using orientation tests and determine the boundary points that form the hull.

### Q6 – Exhaustive Search
Solve a package-selection problem by examining possible subsets and selecting the combination that maximizes value without exceeding the given capacity.

### Q7 – Day-4 Design Challenge
Redesign the closest-pair algorithm to reduce unnecessary distance calculations and compare its performance with the original brute-force approach.
