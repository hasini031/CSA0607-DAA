# CO3 Assignment – Design and Analysis of Algorithm

## Assignment Overview
This assignment focuses on implementing and analyzing different algorithm design techniques. It includes Divide and Conquer, sorting algorithms, advanced multiplication techniques, computational geometry, and independent algorithm design.

The main objective is to understand how algorithms work, implement them using Python, analyze their time and space complexities, and compare their performance using different test cases.

## Questions Covered

| Question | Topic |
|---|---|
| Q1 | Max-Min Algorithm and Binary Search |
| Q2 | Merge Sort and Quick Sort |
| Q3 | Karatsuba Multiplication |
| Q4 | Strassen Matrix Multiplication |
| Q5 | Closest Pair of Points |
| Q6 | Median of Medians and Meet-in-the-Middle |
| Q7 | Day-4 Independent Design Challenge and Joint Design |

## Repository Structure

- **Q1_MaxMin_BinarySearch:** Implementation and analysis of Max-Min and Binary Search.
- **Q2_MergeSort_QuickSort:** Implementation and comparison of Merge Sort and Quick Sort.
- **Q3_Karatsuba:** Karatsuba multiplication algorithm and performance analysis.
- **Q4_Strassen:** Strassen matrix multiplication and comparison.
- **Q5_ClosestPair:** Closest Pair of Points using Divide and Conquer.
- **Q6_Advanced_Divide_Conquer:** Median of Medians and Meet-in-the-Middle algorithms.
- **Q7_Day4_Design_Challenge:** Independent designs by Student A and Student B, followed by a joint final design.

## Tools and Technologies
- Python
- Google Colab
- GitHub

## Work Distribution
The assignment is completed by two students, Student A and Student B. Both students contribute to algorithm design, pseudocode, implementation, testing, and analysis according to the assigned responsibilities.

## Conclusion
Through this assignment, we understand the practical application of algorithm design techniques. We implement different algorithms, study their time and space complexities, test them with different datasets, and compare their performance to understand their efficiency.
